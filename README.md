# 📅 Reserva2 - Plataforma de Gestión de Turnos

Tu agenda de turnos online gratis. Centralizá reservas, automatizá recordatorios por WhatsApp y cobrá señas sin pagar comisiones extra.

## 🚀 Arquitectura del Proyecto

Este repositorio es un Monorepo que contiene tanto la API como la aplicación cliente:

* **📁 Frontend:** Desarrollado con Angular (TypeScript, HTML, CSS). Interfaz moderna, minimalista y responsiva orientada a la conversión.
* **📁 Backend:** Desarrollado con C# .NET (API REST). Maneja la lógica de negocios, conexión a base de datos y autenticación.

## ✨ Características Principales
* Panel de administración de turnos 24/7.
* Automatización de cobros (Integración con MercadoPago).
* Cero comisiones por transacción.
* Interfaz fluida y diseño UI/UX premium.
